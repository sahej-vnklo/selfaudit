# Blueprint Catalog — Draft

> Units are decomposition signals — not operational inventory.
> Each unit exists because when a top-level metric looks wrong, tracking it separately tells you WHY.
> Rule: if removing a unit means the AI can no longer distinguish two different root causes, keep it. Otherwise cut it.
